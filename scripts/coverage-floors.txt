# CI fails when a system is below its floor, when a system has no floor
# and when a floor names no system. "Total" checks the whole.
#
# Rules:
# - A floor is the measured number minus 0.5, so coverage can never drop
#   unseen. When a system goes up, raise its floor in the same PR.
# - Once a system reaches 95%, its floor becomes 95 and stays there.
# - Never lower a floor to make CI green; add the missing tests.
