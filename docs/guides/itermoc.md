# Itermoc: profiles, models, services and outside agents

Itermoc is one sidebar view for everything that shapes the AI chat. It
reads what termocode already knows and takes you to the screens that
change it. It does not change anything by itself.

## The view

Open it from the command palette: **Itermoc: Open**. The palette also has
one command per section: **Itermoc: Profiles**, **Itermoc: Models**,
**Itermoc: Services** and **Itermoc: Outside Agents**.

The view has four sections:

| Section | What it lists |
|---|---|
| PROFILES | the agent profiles, with the active one marked |
| MODELS | the model slots the steps run on, and whether each has a key |
| SERVICES | the services the chat can reach (MCP) |
| OUTSIDE AGENTS | agents that use termocode's tools, and who is connected |

## Keys

Press `?` in the view for the key card.
