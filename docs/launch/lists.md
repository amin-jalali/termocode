# Lists, directories and newsletters

One short, factual entry each. Submit them in the week after the main
launch, when the repo has a few installs and stars. Submit a PR or a form
yourself; never ask people to upvote.

## One-line entry (for lists)

`termocode` - The AI-Integrated Terminal IDE. Real Neovim inside, git,
debugger, tests, Docker, Kubernetes and databases in one Go binary; AI edits
reviewed per hunk; sessions survive SSH drops. Linux, macOS, Termux.

## Four-line email (newsletters)

Subject: termocode - a terminal IDE with real Neovim inside

termocode is an open-source (MIT) IDE for the terminal, written in Go. The
editor is a real `nvim --embed`; around it are git, a debugger, tests, an
AI chat whose edits you accept per hunk, and sessions that survive SSH
drops. Early release (v0.1) for Linux, macOS and Termux.

## What not to do

- No list that is for plugins only (termocode is not a plugin).
- No second post of the same text in the same community within months.
- Do not mention the opt-in OAuth sign-in for hosted providers in any
  launch text. It is documented in the app with its warning; it is not a
  launch feature.
