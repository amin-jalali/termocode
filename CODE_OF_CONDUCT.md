# Code of Conduct

termocode follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, and keep discussions
about the work. Harassment, insults and personal attacks are not
accepted in issues, pull requests, discussions or any other project
space.

## Reporting

If someone breaks these rules, report it privately to the maintainer
through GitHub (**Security → Report a vulnerability** also reaches the
maintainer privately), or by email to the address on the maintainer's
GitHub profile. Reports are kept confidential.

The maintainer may remove comments, lock threads, or block people who
break these rules, as described in the Contributor Covenant's
enforcement guidelines.
